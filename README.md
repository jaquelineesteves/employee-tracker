 # Employee Tracker SQL
  ![MIT](https://img.shields.io/static/v1?label=License&message=MIT&color=blue)
  
  ## Description 
  As shown in the video, it is an application that builds tables in the database, you can add objects and show tables using command Line. technologies: PostgreSQL, Node.js.

   ## Installation 
  To install necessary dependencies, run the following command:

```
   npm i

```

  ## Usage
  The user has to clone this repo, go to db/connection.js fill your postgres user and run in command line, it will show options to Use the program.
```
   npm run start

```
